# Poll Messenger

Лабораторная работа по ИПО, которая продолжалась поддерживаться после сдачи

## Структура проекта

Проект состоит из 3х модулей:

### common

общая библиотека, содержащая DTOs, структуру сообщений и прочее. В общем случае этот модуль можно описать как интерфейс между двумя остальными модулями, позволяющий взаимодействовать им между собой

### sever

TCP сервер, DAO для доступа к СУБД PostgeSQL. 
Сам сервер многопоточный (виртуальные потоки), где 2 потока - это 1 клиент. 

1. выделяется на отправку синхронных сообщений. 
2. long poller. Держит очередь сообщений и, при добавлении сообщения в очередь сервером, отправляет сообщение на соответствующий сокет клиенту

Чтобы потоки могли общаться с сервером они должны быть авторизованы клиентом

### client

Клиент работает на двух TCP сокетах.

1. отправляет/слушает синхронные сообщения
2. long poller.
